顺序（他亲自确认，以此为准）：

锅炉 → 多管除尘器 → 脱硝器（SCR 反应器） → 省煤器 → 布袋除尘器 → 空气预热器 → 脱硫塔（内含 水膜除尘）→ 烟囱

工艺是 SNCR + SCR 联用：

  1. 炉膛里喷尿素：850℃ 以上分解出氨，先跟 NOx 反应掉一部分（SNCR）
  2. 烟气先进 多管除尘器（一级除尘）
  3. 再进 脱硝器：里面有像煤球的固体催化剂（SCR），把剩下的一次反应完
  4. 后面才是省煤器、布袋、空预器、脱硫塔

更正之前记错的两条：

  • ~~脱硝在锅炉出口、除尘器之前~~ → 脱硝器在多管除尘之后
  • ~~没买过催化剂、脱硝形同虚设~~ → 有催化剂（颗粒/球状固体），只是尿素用量少

压力管道基础目录

作用：用排烟余热加热给水。排烟温度每降 15～20℃，约省煤 1%。

位置：水侧在给水泵之后、锅筒之前；烟气侧在过热器之后、空预器之前（本厂：旋风除尘 → 省煤器 → 布袋 → 空预器）。

水路线：除氧器 → 给水泵 → 给水调节阀 → 下集箱 → 蛇形管 → 上集箱 → 锅筒。

类型：钢管式（承压高，大中型炉用）；铸铁式（带鳍片、法兰连接、耐腐蚀，低压小炉用）。本厂 1.9 MPa / 170℃，肯定是钢管式。

结构：大箱体内一排排蛇形管，给水从下集箱进、上集箱出；烟气管外横向冲刷，管上可焊螺旋鳍片；侧面留吹灰器接口，下面有灰斗。

再循环（不是"平时走的路"）：

  • 平时给水连续流过，本身就是直通锅筒的，不用开
  • 点火、停泵、低负荷、给水一停，省煤器成了死管，水不动就会被烟气烤开、汽化 → 管壁超温爆管
  • 所以点火时省煤器管内的水必须在动：给水在流、或开再循环、或上水排污，流到哪都行，就是不能是死水
  • 给水连续投运后关再循环

开产顺序：

  1. 上水到略低于正常水位
  2. 开再循环
  3. 点火、升温升压
  4. 水位下降后给水泵断续补水
  5. 给水连续后关再循环，转正常水位控制
  6. 并汽

两个小阀门：下集箱最低位是放水阀（放水、排空、冲洗，不是日常定排）；上集箱最高位是放气阀（上水排气、停炉放水前先开）。放气多为手动，见连续出水就关。

停炉：短期热备用保持满水防腐蚀；长期排炉排空、干燥或充氮；冬天必须防冻。
